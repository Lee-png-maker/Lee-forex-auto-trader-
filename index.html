Installation guide

  1. Create and maintain the source code in this GitHub repository.
  2. Access MT5 on a Windows computer.
  3. Open MetaEditor and create an MQL5 Expert Advisor.
  4. Paste in the robot's MQL5 source code.
  5. Compile and resolve any errors.
  6. Test using the MT5 Strategy Tester.
  7. Run it on your RCG Markets demo account.
  8. Verify position sizing, stop-losses and daily risk controls.
